# Aurora Client releases

Installers for the **Aurora Client** Minecraft launcher (1.21.11, Fabric).

Download the latest `AuroraClient-Setup-x.y.z.exe` from [Releases](../../releases/latest). Once installed, the launcher updates itself automatically from this page.

This repository only hosts release files for the updater. The source code is not public.
